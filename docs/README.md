## Rules for future work

1. Work only in this Final Showcase folder unless a different checkout is explicitly named.
2. Keep every public route on the shared root layout. Never copy the footer or cursor into a page.
3. `/` uses the published homepage selection, with Hero V1 as its fallback. `/hero-v1` and `/hero-v2` remain explicit variant previews. The new selection requires end-to-end admin verification; see the current admin ledger.
4. Update `WORKING-VERSION.md`, the site-status version and the launcher identity together when establishing a new checkpoint.
5. Move superseded planning notes into `docs/archive/`; do not leave rejected plans beside active specifications without a historical label.
6. Start and open the Final Showcase website on its canonical port **3134**. For admin requests use only **3140** (`npm run admin`, then `/admin`); see `admin-system.md`. Override the website port only for an intentional second simultaneous website, and identify both ports explicitly.
