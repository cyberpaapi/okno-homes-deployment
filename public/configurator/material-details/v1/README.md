# Original company material samples

These 26 files are byte-identical copies of the user-supplied images in `Assests/Cladding_Swatches_Original`. They are mapped to the matching register number and finish name by `scripts/configurator/prepare-detail-swatches.mjs`.

Original dimensions, file sizes and SHA-256 hashes are recorded in `manifest.json`. No artwork, colours, embedded sample markings, or aspect ratios have been edited. Customer detail views use Next.js image delivery at a responsive display size and offer a link to each full-resolution original. Admin material cards also link to the full sample.

The small register thumbnails, 3D PBR maps, company house geometry, and published catalogue choices are separate and remain unchanged. These images are material references, not additional claims about manufacturer specifications, price, or stock.
